# Rive sources

After installing the official Rive CLI, scaffold a project here:

```bash
npm run rive -- create rive/scene
```

Use the CLI's generated RML files and agent instructions as the source of truth.
Preserve editable source here; copy exported SVG artwork or rendered animation
clips to `video/assets/`. Do not rename `.riv` files to `.svg`.

Official installation: https://rive.app/downloads
CLI documentation: https://rive.app/docs/cli/overview
